What the decomposition says the Phase-10 fork should do: not pick one arm, but sequence three levers sized by bucket. (1) **Detector-correctness repairs** (room canonicalization, endpoint exclusion, weak-classifying alibi_conflict, per-claim dedup) — cheap, code-level, orthogonal to both fork arms, and they dismantle the wrong-ejection engine while exposing the genuinely diagnostic CANON_INTERIOR channel (4 impostor-naming genuine flags this set, 0 converted). (2) **An evidence-sharing (testimony-ingestion) belief rule** — the only lever that converts the dominant 27-meeting private-evidence bucket. (3) **Pacing/activity** (crew-callable emergency meeting, more meetings per game) — the accumulator channel is byte-verified working (seeds 6 and 12) but starved at 1.52 meetings/game; pacing multiplies the one proven conversion path and addresses the ~14-meeting b2+c remainder. The impostor toolkit gaps (no blending, no reporting) are the other half of the Phase-10 gameplay contract. Do not gate any of this on ejection_accuracy parity with the 0.63 era — the old number was artifact railroading (14/22 old impostor convictions had zero genuine-shaped flags), not detection.

**C-2 — high — Wrong-ejection mechanics: `alibi_conflict` is never weak-classified (code gap); adversarial counter-alibis and defense-echoes manufacture strong flags.** `_detect_alibi_conflicts` never calls `_weak_signal_reasons` — a self-stated alibi PAIR (same speaker, same turn; seeds 11, 17) gets the full +0.3 while a single self-stated alibi gets 0.08; the 9.7 rationale applies a fortiori but the code path skips it.
