# Current evidence-use decisions

These decisions implement the reasoning card's bounded mechanics. Both new
versions remain OFF by default; this is not an adopting record. The original
three-lever FINDING remains unchanged. The historical hardening counts below
are identifiers of earlier allegations, not newly measured incidence estimates.

## What the scorecard establishes

`uv run python scripts/measure_reasoning_evidence.py --output /tmp/reasoning-scorecard.json`
reproduces the source-bound scorecard. It validates chronology, outcomes and
seeded setup through the existing strict report reader before counting the
300 named recordings and requires all four roster descriptors. Full input hashes,
the exact inventory and runtime hashes are checked before publication.

The current artifact has 36/36 deterministic mechanism cases. In the fixed
recordings, 333 proof meetings have 333 correct ejections; 339 no-proof meetings
have 50 correct ejections, 46 wrongful ejections and 243 skips. These are fixed
outcomes, not candidate outcomes. The corpus contains 645 flags versus 638
independent accounts: seven duplicates across six named meetings. A different
speaker remains a different source. This is not the suspicion-lift cap, which
intentionally caps several witnesses challenging the same alibi.

The scripted reply comparison uses six calls/42 tokens without an added reply
and seven calls/49 tokens with one. No new allegation adds no call. Separate
manager tests cover cancellation, deadline/default, dead speakers, an existing
response, repeated prose and distinct observation attribution. Latency is a
local scripted-provider observation, not a provider forecast. Correction and
wrongful-ejection rates for new model decisions are undefined: there are zero
eligible fresh-model decisions.

The renderer measurement intentionally exposes loss: its co-present three-ID
fixture retains all three IDs in the store while rendering one shared citation
at each tested budget. Zero invented IDs is an integrity property, not full
retention. The existing memory-render tests separately exercise interrupted
spans, movement and budget truncation; this artifact is not a full corpus gauge
of every derived sentence.
