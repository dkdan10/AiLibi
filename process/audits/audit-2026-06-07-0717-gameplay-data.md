## 3. Confirmed bugs & rule violations

### 3.1 Mechanical findings (code-certain)

**MECH-B-1 — 25 impostor kill intents rejected cross-room (HIGH, intent-generation waste).** Across 19/50 seeds, impostors queued a kill on a target not in their room; the engine rejected each ("kill requires same room") and the impostor no-opped the tick. 25 rejections (seeds 0,14,19,22,40,43 ×2; 13 seeds ×1), all IMPOSTOR-role actors. This is a producer-side fault — the kill-intent path selects a victim from a stale/out-of-room belief. Evidence: seed 0 tick 4, p-6's kill rejected; seed 19 tick 4, same shape. Repair: filter candidate victims to the actor's current room at intent time or re-validate immediately before queuing. Each rejection burns the impostor's tick — 25/164 kill attempts (15%) wasted, which weakens impostors mechanically and partially confounds behavioral win-rate reads.

**MECH-B-2 — 85 dead-player queued actions rejected, all exact same-tick kill races (INFORMATIONAL).** 85 actions across 38 seeds (50 do_task, 28 move, 7 wait) rejected with "player is dead"; verified for all 85/85 that the actor's kill tick equals the rejection tick — downstream symptoms of intra-tick ordering (victim's action queued before death resolved), not independent violations. Evidence: seed 0 tick 14, p-7's move rejected on p-7's own kill tick. No repair required; engine behavior is correct and deterministic.

## 4. The conversion pipeline (headline)

The detection→ejection funnel, stage by stage, across all 78 meetings:

| Stage | What | Count | Survival |
|---|---|---|---|
| 0. Discovery | kills → body-report meetings | 139 → 78 | 56% (61 bodies never found; 7 games meeting-less) |
| 1. Detection | openings with sightings / kill-witness chains placing a true impostor at the body room ±5 ticks / killer literally seen at the scene at discovery / contradiction flags | 60/78 / 21/78 (20 = actual killer) / 19/78 / 16 flags in 15 meetings (8 naming a true impostor) | healthy |
| 2. Accusation | openings that accuse / accusations at true impostors / meetings with a true impostor publicly accused / actual killer named | 63/78 / 46/66 = 70% (74% excl. 4 corpse-targets) / 45/78 / 39/78 | healthy — ~3x chance precision, unopposed |
| 3. Corroboration | replies that counter-accuse / opt-ins that accuse / meetings with a 2nd named target | 0/59 / 1/30 / 2/78 | structurally thin: one citable thread per meeting |
| 4. **Ballot** | non-skip ballots / non-accuser conversion in the 45 impostor-accused meetings / accuser follow-through | 35/527 (93.4% SKIP) / **3/171 = 1.75%** / 21/46 (54% abandon their own accusation) | **DEAD — this is the stage** |
| 5. Tally | flips needed to eject in impostor-accused meetings {1:1, 2:6, 3:11, 4:15, 5:12} / max tally ever | closest miss 1 flip (seed 2 m2, 2v3) / 2 votes | multiplier on stage 4 |
| 6. Ejection | ejections / contradiction-meetings converted | **0/78** / 0/15 | zero |

**The single stage where conversions die: stage 4, the individual non-accuser ballot.** The proximate mechanism is identified, not speculative: in all 19 cases where a SKIP rationale quotes a numeric suspicion, the value is ≥0.6 — above the §4.6 threshold — yet the voter skips, 13 explicitly claiming the threshold is unmet (seed 44 m1: p-3 skips with "suspicion on p-5 at 0.80, but this is not high enough"; seed 13 m2: p-4 skips quoting 0.90 on impostor p-1 — in an impostor-win game; seed 10 m0: "0.70... does not meet the threshold of 0.60"). 364/492 skips emit confidence exactly 0.60 (a patterning artifact). The tally's own confidence check never blocked anything (all 35 non-skip ballots ≥0.65); vote COUNT, starved by wrongful skips against a bar requiring votes to strictly outnumber SKIPs (3–5 simultaneous conversions at observed tables), is the sole blocker. Even ground-truth eyewitness meetings — crew witness in the kill room, correct accusation at confidence ≥ the 0.6 gate — ended SKIPPED with the accuser themselves sometimes skipping (seed 9 t8, seed 31 t16, seed 2 t14, seed 26 t6).

**Healthy substrate or new degeneracy?** The synthesis brief asked about the "crew-favored 74%-by-stopwatch split" — note first that 74% is the stale anchor; the committed set is **92%-by-stopwatch** (46/50, every crew win CREWMATE_TASKS). It is a **mirror-image degeneracy**, not health: where the old 7p2i baseline was impostor-dominated with hollow meetings, this one has rich meetings with zero causal path to any outcome — all 50 results were decided by the deterministic task/kill race, and the 694-call/1.34M-token deliberation layer was outcome-inert. The crew's 70% accusation precision is also **unopposed**: impostors authored 0 of 66 accusations, never counter-accused in 45 replies, never reported, never used vent/sabotage/pretend-task, spent 52.4% of their ticks WAITing, and averaged 2.78 kills against the 5 needed for parity [D-D-2, D-D-4, D-D-5] — so even stage-2 health is partly a gift. Every one of the 4 impostor wins came after a true impostor stood accused and the table skipped [C-C-1]: had conversion worked at all, the split would be even more lopsided. **Verdict for Wave-1: the baseline is usable as a measurement substrate for conversion-denominated metrics (denominators are healthy), but the game itself is degenerate in both directions — inert deliberation and a saturated win split — and win-rate must not be a Wave-1 gate.**

## 5. Gameplay trends & pacing

- **The restructure DID lengthen the race — and overshot the balance target by 66 points.** Median game 21 ticks (15–28, mean 21.1) vs 7p2i's median 15 (7–24, mean 14.7): ~+40% longer. But impostor win rate went 74% → 8% (4/50, all IMPOSTOR_PARITY). The task clock completes at median tick 21 (global completion 0.21@t5, 0.51@t10, 0.74@t15, 0.92@t20) while impostors average 2.78/5 kills (per-game: 1×9, 2×13, 3×12, 4×12, 5×4) at median 8-tick per-killer intervals against a 4-tick cooldown [B-B-3].
- **Impostor wins require near-perfection.** All 4 parity wins share a tick-4 first kill (earliest legal) plus continuous tempo (seed 12: kills at t4,7,11,15,19); 0/29 games without a tick-4 opening became impostor wins; 12 crew-win games reached 4 kills and still lost; even the wins ended with crew at 75–90% task completion [B-B-3].
- **Kills actively accelerate the crew clock.** Under the corrected accounting, 11/46 crew task wins are kill-dependent (committed report says 8 — A-A-2); 143/700 task instances (20.4%) were removed by kills via the §3.5 dead-owner drop; mean instances complete at win 11.3 vs 14 seeded. The impostor FSM treats every kill as progress; late kills are often self-defeating [D-D-4, F-F-7].
- **Kill geography: the hub is the killing floor; dead-ends are information black holes.** CAFETERIA hosts 40/139 kills (29%) including all 21 tick-4 spawn-cluster kills; first-kill median tick 7. 61/139 kills (44%) never produce a report — unreported bodies concentrate in REACTOR 17 / STORAGE 12 / ADMIN 12, while reported kills concentrate in CAFETERIA (33/78). - **Meetings: 1.56/game, clustered ticks 8–16, all body-triggered.** Per-game histogram 0:7 / 1:21 / 2:13 / 3:5 / 4:4; meeting_rate 0.86 (43/50 games — above the 0.60 Stage-A gate, below the briefed ~0.96). 0 emergency meetings in 8,645 logged actions: the button is structurally unreachable under current policies — only 6/139 kills had a crew witness, every witness was standing next to the fresh body, and all 6 filed a body report the next tick [B-B-5, B-B-8].
- **Set health is otherwise clean.** Impostor slot seeding non-degenerate (7–14 per slot over 100 impostor-games); all games end naturally at tick 15–28 (budget 1000, never approached); 0 failed calls; fixed-defect list stays fixed [B-B-9].

## 6. Decision-quality findings

### Crew side

- **§4.6 threshold misapplication is the binding constraint** (C-C-2, HIGH): suspicion mechanics readily cross the gate (default 0.5, body-proximity +0.2, contradiction +0.3), and voters walk in at 0.70–0.90 — then skip anyway, 19/19, with 13 explicit threshold misreadings. The 7B model cannot reliably do the ≥ comparison the prompt delegates to it.
- **Accusers abandon their own accusations** (C-C-4, HIGH): 25/46 impostor-accusers (54%) skip on the player they just publicly accused (41/66 = 62% overall abandonment); vote_ballot.j2 gives the voter's own fresh accusation no standing, and rule 3 even tells them primary_reason_id should be null for self-observed cases. The "free" first vote toward the 3–5 needed materializes only half the time.
- **No public pile-on is possible** (C-C-5, MEDIUM): 0/59 replies counter-accuse, 1/30 opt-ins accuse, so voters see one accuser's claim plus a denial. Both 2-vote meetings (the set's best tallies) had a second citable thread — the exception that proves the lever.
- **Corpse accusations** (A-A-4, F-F-6): 4/78 openings burn the meeting's only accusation on an already-dead player (3 accuse the very corpse being reported, e.g. seed 30: the victim's "actions may have contributed to their own demise"). Contaminates precision denominators (0.697 → 0.742 when excluded).
- **Detection quality is real**: 46/66 accusations at true impostors (~3x chance), 39/78 meetings name the actual killer of the reported body, ballot precision 27/35 = 0.771 when crew do vote. All 3 genuine impostor kill-window lies drew alibi_vs_sighting contradictions — caught 3/3 [D-D-3].

### Impostor side

- **Total meeting passivity** (D-D-2, HIGH): 0 accusations, 0 counter-accusations (44 alibi + 2 corroboration replies), 0 reports (78/78 reporters are crew), 0 opt-in accusations in 20 turns. Prompt-shaped: accusation_round.j2 explicitly offers "stay purely defensive" and qwen takes it every time. Impostors survive on crew conversion failure (max pressure ever: 2 ballots), not deflection.
- **Alibi "fabrication" is mostly self-incriminating truth** (D-D-3, HIGH): of 38 killer self-alibis about their own kill, 20 truthfully name the kill room (11 even cover the kill tick); only 3 lie about the kill window — all 3 caught. The 0.836 alibi-survival metric measures uncontradictable honesty, not deception skill; do not read it as impostor effectiveness.
- **Toolkit gap quantified** (D-D-5, MEDIUM): impostors used exactly three action types (wait 1160 / move 885 / kill 167). Vent/sabotage exist in the engine but are unreachable from the FSM (no intent imports); pretend-task never fires; body-reporting is policy-forbidden, making impostor_report.j2 — the only prompt that coaches impostor accusations — dead code (0/78 impostor-opened meetings).
- **Coordination is thin and self-harming** (D-D-6, MEDIUM): 3 teammate corroborations in 50 games; 4/20 opt-ins are verbatim copies of the teammate's reply (an obvious collusion tell); seed 18 m1 has a killer's own sighting placing his teammate in the body room — the 7.12 firewall bans accusations, not scene-placing observations. The competent exemplar: seed 13 m2 (rebut the premise, teammate corroborates with consistent ticks) preceded a parity win.
- **Post-kill stealth fails** (D-D-7, LOW): in 19/78 meetings the opening's sightings place the actual killer in the body room at discovery — all 19 at kill+1. One-step COVER plus 52% wait share keeps killers loitering at the scene; this is the dominant source of at-impostor accusations.

## 7. Chain-protocol dynamics

- **Mechanically flawless**: termination re-walk, turn-id/order, reply_to, opt-in containment, firewall, dangling-reason, dead-speaker checks ALL CLEAN (extractor, code-certain). 0 impostor-at-impostor accusations or ballots across 90 turn-claims / 527 ballots — the 7.12 firewall holds completely.
- **Termination mix**: no_new_accusation 74/78; target_not_living 4/78 (the undocumented-but-coded fourth guard, §3.2 above); cycle-detection and turn-cap **never fired**. Chain lengths: 1×19 / 2×59 — no chain ever reached 3 turns, so §5.2 conditions (b) target-already-spoke and (c) turn-count==living occur zero times in 78 meetings [F-F-5].
- **Engagement**: 63/78 openings carry an accusation; 65/66 accusations are opening-turn (1 opt-in, 0 reply); replies never counter-accuse. The chain shape is "opening accuses → accused denies → vote," every time.
- **Opt-in gate is tight, not loose** (E-E-7): derived-eligible 30 == recorded 30 (gate exact); 29/30 substantive; the single empty pass is seed 38 m0 turn 2 (pure speculation, no observations/claims). If anything the gate is too strict for corroboration purposes — 30 opt-ins across 78 meetings means witnesses rarely speak.
- **Ballot-chain coupling works**: 29/35 non-skip ballots cite a turn accusing their target; 0 non-skip with null primary_reason_id; 0 dangling reason ids; 0 dead voters.
- **Order effects**: the opening turn is the whole game — it carries the body report, the only accusation, and (in 19 cases) the killer-at-scene sighting. Everything downstream is denial and skips.

## 9. Metric soundness, coverage & balance

- **Ejection-denominated metrics are null and cannot anchor Wave-1** (F-F-2, HIGH): vote_correctness_rate and ejection_accuracy are null (0 ejections; small_n flag correctly True — the analyzers fail soft, not silently). **Named Wave-1 lead-metric recommendation: the conversion pair — (a) accusation-followership = non-accuser ballots on an accused player per accusation-meeting, baseline 7/63 = 0.11; (b) contradiction-meeting→ejection conversion, baseline 0/15 — with ballot precision (27/35 = 0.771) as the regression guard** so followership gains aren't bought by spraying wrong votes. Secondary: accuser follow-through (21/46 = 46%, target ≥80%), non-accuser conversion in impostor-accused meetings (3/171 = 1.75%), max per-meeting tally (2). Promote ejection_accuracy to headline only once total_ejections ≥ VOTE_CORRECTNESS_MIN_SAMPLE (10).
- **PromptRegressionMetrics is blind to the Wave-1 objective and cost-blind on Ollama** (F-F-3, HIGH): the A/B record contains no ejection_accuracy, no skip share, no conversion metric, and no token totals — total_cost_usd is identically $0.00 on qwen, so a prompt change that doubled the 1.34M input tokens would show zero cost delta. Schema-additive fix required before any A/B.
- **meeting_rate no longer discriminates** (F-F-4, MEDIUM): 0.86 on a games-with-meeting basis, movable only via the 7 zero-meeting games (which lack meetings for map reasons). The discriminating scalar nothing computes: per-kill body-report conversion = 78/139 = 0.56.
- **Coverage zeros** (F-F-5, MEDIUM): kills/rooms/pairs/lengths are diverse (26 distinct impostor pairs; kills 1–5 per game across 9 rooms), but the deduction axis has literally zero baseline variance: 0 ejections, 0 emergency meetings, 0 chains ≥3, terminations (b)/(c) never fire, 0 reply accusations, first_zero_impostor_tick null ×50. Post-patch movement on these axes is novel territory, not a measured delta; every impostor-death code path is dormant-untested by this set.
- **Metric contamination items**: kill_gifted undercount (A-A-2, §3.2); corpse accusations depress precision 0.742→0.697 (F-F-6); alibi survival 0.836 dominated by truthful self-incrimination (D-D-3) — split lie-survival from trivially-true alibis before quoting it.
- **Balance** (F-F-7, HIGH): 92% crew, all by task-stopwatch, with meetings causally inert, is a mirror-image degeneracy (full argument in §4). Win split is not a valid Wave-1 A/B outcome; each successful ejection only removes the parity path and pushes toward 100/0 — an impostor-side clock lever (sabotage/slowdown) is the eventual counterweight.
