# Compare recorded deduction mechanisms on a finite scenario matrix

**Status:** done

## Outcome

One bounded offline command runs declared scenario/profile comparisons through
real game recording and strict report/API readers. It exposes what changed,
what agents knew, which accusations received answers and what ballots decided.
Scripted responses demonstrate mechanisms, without becoming model-quality
evidence. The same definitions prepare a later separately budgeted evaluation.

## Evidence

The [authorized plan](../post-review-plan.md) requires trustworthy experimental
evaluation before adoption. The [review](../../audits/review-2026-09-06/REVIEW_REPORT.md)
finds certified vent results dominate the existing meetings and that prior
mechanics scorecards do not measure fresh decisions. The temporal and public
account cards provide real canonical-map scenarios and recorded profiles.

## Constraints

Follow architecture Layering, Enforced boundaries and Determinism and the
substrate ladder. Use the deterministic scenario provider only. No live calls,
new maps/roles, dependencies, historical changes, training, adoption or merge.
Declare scripted metrics as mechanics. Development cases are not held-out
confirmation, even when their inputs were frozen before an offline capture.

## Record impact

New experimental fake-provider captures only; none adopt a profile. Historical
inputs and metrics remain unchanged. The captured source list, explicit profile
and recorded provider outputs define reproducibility. A later runtime edit makes
this capture historical rather than silently refreshing its meaning.

## Validation

Run `.venv/bin/python -m experiments.deduction_evaluation` into a new output directory,
then validate its actual recordings through current readers. Focused tests plant
source drift, conflicting settings and incorrect expected witness counts. Run
`bash scripts/check.sh` and `bash scripts/verify_samples.sh` after independent
review. Record the final CLI arguments, outcomes and limits in Results.
