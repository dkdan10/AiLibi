**Why:** the lab proved the binary win split is "purchasable wholesale" (`report-stopwatch-lab.md`), so

(`report-grounding-audit.md`) found the rubric **unsafe as raw Phase-C fitness** (perverse R2/R3/R7

**held-out geomean referee**. It stays $0/offline (reads committed extractor facts) and re-scores on any
facts JSON.

**Score (0–100, per game, decoupled from who won):**
`100 × floor_multiplier × geomean_weighted(D1..D4)` (Task 13.15; weights D1 0.40 / D2 0.25 / D3 0.15 /
D4 0.20, epsilon 1e-3) — the additive `0.35·R1 + …` sum this report used to document is REPLACED; one dead
dimension now sinks the score, and the R4-style **floor zeroes** a game on a firewall/determinism breach,
friendly fire, or a **railroad ejection** (a crewmate ejected below the gate or with no backing evidence).
The per-game `r1_decisive` / `r2_deception` / `r3_arcs` / `r7_legible` keys are still emitted separately
(multi-objective axes for Phase-C; the D1–D4 breakdown lives in `results-rubric-geomean.json`, lab-local).
