## Pre-ML Grounding Audit — `rubric_score.py` as Phase-C Fitness

**Scope:** `experiments/lab/rubric_score.py` is about to become the neuroevolution fitness/referee (`ml-spike-charter.md:35`, MEMORY `project_ml_agents_plan`). Per-game score is fixed at `100*(0.35*R1 + 0.25*R2 + 0.20*R3 + 0.20*R7)` (`rubric_score.py:311`). All findings below survived an adversarial skeptic; refuted items are explicitly dropped. Two angle reports referenced visibility probes whose outputs were undefined here — those probe-number-dependent claims are reported with that caveat.

---

### 1. Rubric construct-validity

**SOUND**
- **R1 (0.35) is the one construct-valid term.** `r1=1.0` fires only on `CREWMATE_EJECT` (`rubric_score.py:280`), which `engine/win_conditions.py:45-46` raises iff `alive_impostors==0`; since crew cannot kill impostors, this faithfully means deduction cleared the board. Keep R1's definition unchanged (verdicts RB-7/G8 confirm).
- The rubric degrades sensibly on meeting-sparse rosters (4p1i mean 12.6, 31/50 at 0.0) — a regression invariant any refactor must preserve (RUB-CAL-6).

**FLAWED**
- **R1's gradient is inert to the trainable layer.** FO-3 (`experiments/lab/ml_spike/fo3_rubric_goodhart.py`), reproduced by two independent verifiers, shows a 2.1x kill swing (19→40 resolved) leaves R1 pinned at 0 under fake meetings. The high-WEIGHT correct term cannot be moved by tactical play; the low-weight gameable terms float (G8/G4). This mis-prioritizes any "R1 is fine, ship it" conclusion.

### 2. Rubric calibration

**SOUND** at the extremes — top-3 games (seeds 5/47/34) are genuinely rich, true-bottom (seeds 3/19) genuinely dull (RUB-CAL summary).

**FLAWED**
- **R2 is ANTI-correlated with the total score (Pearson −0.281; corr(R1,R2)=−0.693).** Top-10 games average R2=0.36 vs bottom-10 R2=0.58; all 6 eject-decided games have R2=0.2. Because `r1=1.0` forces both impostors into `gone` → `survived_accused=0` → R2 collapses to the 0.2 branch (`rubric_score.py:280-297`), an optimizer climbing the weighted sum is pushed toward "both impostors caught" and AWAY from `rubric.md:36`'s stated intent ("a 100% deception rate is as dead as 0%"). Verified exactly from `results-rubric-score.json` (RUB-CAL-1).
- **Within-meeting deduction richness is invisible.** A 7-turn meeting where two crew correctly name the impostor and a teammate corroborates a false alibi (seed 37) scores the SAME 15.0 as a 2-turn nothing (seed 3): R3 zeroes below 2 meetings (`rubric_score.py:305`) and R7 zeroes with no structured flag (`:308-309`), so the rich rhetorical case — exactly the testimony-ingestion lever the roadmap flags — is unscoreable (RUB-CAL-2).
- **`_win_shape` collapses all IMPOSTOR* reasons into one bucket** (`rubric_score.py:242`), so a sabotage-win can never register as a distinct R5 shape (RUB-CAL-4, low).
- **Provenance hygiene:** the lab-local `experiments/lab/results-rubric-score.json` stamps `git_head=d8cb869` (scoring HEAD, a docs descendant) rather than the set version `1e48c40`; the SERVED copy is correct (RUB-CAL-5, low).

### 3. Goodhart risk (the P0 cluster)

This is the decisive area. **At least three of four scored terms have a verified degenerate maximizer**, and the project's own FO-3 proves the tactical layer can move the cheap proxies while the genuine terms stay pinned — the exact structural setup for Goodhart.

**FLAWED**
- **G2 — R3 rewards the railroad R4 forbids (verdict: holds, HIGH).** `r3 = (0.5 + (0.5 if carry_eject else 0.0)) if n_mtg>=2 else 0.0` (`rubric_score.py:300-305`). `carry_eject` is satisfied by an ejection whose target has ZERO contradictions naming it — i.e. a flagless conviction. Verified: ALL 43 games with ≥2 meetings score R3≥0.5; seed-15 ejects an INNOCENT crewmate yet scores R3=1.0 (20 of 45 points); 4/12 R3=1.0 games convict in meeting-0 (no cross-meeting arc possible). R4 is computed only as orientation rows (`rubric_score.py:123-141`), NOT in the score, so it does not neutralize this. The `>=2 meetings` half is farmable via body-report / `EMERGENCY_COOLDOWN_TICKS=6` (`crewmate_policy.py:109`).
- **G3 — R2 pays for passive survival and "prefers to lose slowly" (holds, MEDIUM).** `survived_accused` = alive-and-not-ejected with no active-deflection gate (`rubric_score.py:270-297`). All 16 stopwatch-no-eject games (R1=0.0) bank R2=0.6. A lose-while-accused-alive game (R2=0.6) outscores a win-unaccused game (R2=0.4) by +5 points, and since every impostor-win yields R1=0.0, this is not swamped by R1. `rubric.md:30-36` itself demands the ACTIVE subcount; the scorer ignores it.
- **R7 reward-flag-presence-not-quality (G1 rubric-hygiene half holds; the "ML impostor mints flags on demand" exploit framing was REFUTED).** `r7` counts raw `n_contradictions>0` (`rubric_score.py:308`, `extract:1731`), no cap, no strong/weak filter. The exploit claim that an ML impostor would farm this is dropped: `experiments/lab/ml_spike/core.py:147-184` shows the ML layer overrides only Move/Wait and delegates ALL meeting speech to the frozen LLM, and no ML fitness reads R7 — so there is no channel to mint flags and FO-3 shows tactical play cannot move R7. The residual SOUND finding is a latent rubric-presence-vs-quality gap, severity LOW.
- **G4 — the decisive structural mismatch (holds, HIGH).** Maximizing the raw scalar pushes toward the physically-reachable proxies (R3 meeting-presence + R2 passive-survival = 45% of weight; verified: R3 `n_mtg>=2` gate moves 2/12→11/12 random→FSM purely via kill-rate) while the genuine R1 (35%) stays inert under any fake/surrogate harness lacking a real vote model. Using the scalar as the tactical inner-loop objective optimizes the gameable terms — i.e. noise + degeneracy.

**Dropped:** R5-monoculture and ballot-follows-chain-Goodhart (G6/G7) are real metric-design notes but NOT in the per-game fitness, so they cannot corrupt selection; demote to diagnostics.

### 4. Detector calibration

**FLAWED**
- **R7's "evidence" is 100% weak flags on this baseline (CAL-2, holds).** ALL 112 contradiction flags across 50 games are WEAK `alibi_vs_sighting` (+0.08), ZERO strong; 65% precision. A lone weak flag lands at 0.58, below the 0.60 §4.6 gate by design (`beliefs.py:54`), and impostor suspicion is identical with vs without a flag (0.679 vs 0.664). So the 20%-weight R7 term rewards low-precision flag presence that cannot eject anyone, not decision-moving signal. The weak/strong classifier (`is_weak_contradiction`, `transcript.py:543-562`) exists and is used elsewhere but NOT for R7.
- **Suspicion separates impostors by VISIBILITY, weakly (CAL-1, holds).** Mean rendered suspicion impostor 0.668 vs crew 0.546 (separation 0.122). The vent signal (rendered 1.00) is impostor 74/74 vs crew 0/74 — a mechanical "you were SEEN venting" tell, not deduction. 36% of impostor-views are effectively undetected (≤0.55). R1/R2 therefore partly measure whether the impostor got physically seen, not whether deduction worked.

### 5. Meeting / vote architecture

**SOUND** — the vote machine itself is well-built: the accusation↔ballot decoupling is deliberate and guarded (`guard_ballot_target_graph`, `manager.py:2299-2391`), the §4.6 tally is mechanical and replay-safe, and "accuse X / vote Y" is the correct anti-railroad guarantee (MVA summary, MVA-1 architecture half verified).

**FLAWED**
- **Spoken accusation never enters a listener's pre-vote belief (MVA-2, holds).** The pre-vote +0.05 bump fires ONLY for observation-backed `independent_voices` (`manager.py:1900-1912`, `beliefs.py:781-789`); a bare rhetorical accusation takes only the POST-vote bump and "can never move the meeting it was uttered in." This is the documented dominant missed-conversion bucket (Phase-9 b1=27: 22/27 witnesses voted the impostor and lost plurality). The core social-deduction loop is architecturally half-disconnected, and R7/R3 score across that gap.
- **`ballot_follows_chain` measures a coherence the architecture suppresses (MVA-1/RB-1, holds, MEDIUM).** 226/349 (65%) non-skip ballots carry `primary_reason_id=null` BY DESIGN (`vote_ballot.j2:137-142` instructs null when the vote rests on own observation), capping the metric near 35%. It is NOT in the per-game fitness, so demote to a diagnostic and keep it out of any aggregate.

### 6. Information model

**SOUND** — the contradiction detector chain (visibility → perception → `saw_player` → `alibi_vs_sighting` → belief Rule 2) is internally coherent.

**FLAWED**
- **The detector is firsthand-witness-only (VIS-1, holds, severity adjusted to MEDIUM).** 111/112 committed contradictions are `alibi_vs_sighting` (someone SAW the subject); only 1 is the inferential `alibi_conflict`. There is no absence-of-alibi / unaccounted-time rule. So R7 (~20% of fitness, ~21% realized) is a function of "was the impostor seen?", a hidden visibility parameter. NOTE: the claim's "~40% of fitness is visibility" over-attributed R3 (R3's carry term is the INVERSE of the detector) and "111 strong" is wrong (all 112 are weak) — the corrected scope is ~20%.
- **DROPPED:** VIS-5 (room_local conflicts with the Phase-C surrogate) was REFUTED — the FO-6 surrogate is already room-only (`ml_spike/core.py:267-272`), so room_local does not starve it. VIS-2's "69% kill-witnessing" figure is a submitted-vs-resolved overcount (corrected ~60%); the visibility-as-a-frozen-knob hygiene point stands but rests on probe outputs undefined in this run, so treat as advisory.

---

### Cross-cutting verdict

The rubric is a usable coarse offline RANKER. It is unsafe as a raw neuroevolution fitness because (a) R2/R3/R7 each have a verified perverse gradient, (b) the meaningful 55% (R1 + true-R7) is provably unreachable by the tactical layer, so a tactical optimizer climbs the degenerate 45%, and (c) the rubric is meeting-driven and the meeting layer is exactly what ML cannot move — confirming the spike's own conclusion that a real/surrogate meeting model must be in the inner loop, with the rubric used only as a held-out SELECTION gate after fixing the perverse terms.
